# NetBoost Command Center v1.0.1

This patch release focuses on Web UI stability and local safety/privacy hardening after the first public release.

## Fixed

- Fixed Web UI loading and button feedback states for long-running actions.
- Fixed Scheduled Task last-run display for Windows sentinel dates.
- Fixed theme switching in Settings.
- Added native file/folder picker support for configurable paths.
- Rebuilt the bundled Web UI assets.

## Safety and Privacy Hardening

- Scheduled Auto-DNS creation now requires explicit confirmation because it is a persistent Windows logon task.
- The local backend no longer force-kills another process when port `47812` is occupied.
- API session checks now protect all API endpoints except health/static assets.
- Session cookie is marked `HttpOnly`; query-string session tokens are no longer accepted.
- CORS is restricted to the exact local backend origin.
- Background runspaces and owned dialog child processes are stopped when the backend exits.
- Per-job event logs are capped in memory, and cleanup paths are hidden by default unless detailed logging is enabled.

## Verification

- PowerShell parser check passed for the backend.
- `npm run lint` passed.
- `npm run build` passed.
