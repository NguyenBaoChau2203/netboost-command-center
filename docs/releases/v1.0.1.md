# NetBoost Command Center v1.0.1

This is the first clean public release of NetBoost Command Center: a local-first Windows network and cleanup toolkit with both CLI and Web UI modes.

## Highlights

- Added a guarded CLI Cleanup Center with safe, confirmed, and advanced cleanup groups.
- Added Windows temporary-file, Prefetch, Recycle Bin, crash-dump, component-store, and Windows Update download cleanup.
- Shared one cleanup target dispatcher between the CLI and Web UI so both interfaces apply the same safety rules.
- Replaced the npm-oriented project workflow with pnpm and removed the npm-to-pnpm conversion feature.
- Replaced GitNexus metadata with a CodeGraph-ready project layout.
- Added the Mochi Cat brand artwork and a script that creates a branded Windows shortcut.
- Added `NetBoost Command Center.exe` with the Mochi Cat icon embedded, CLI-first startup, UAC elevation, and safe forwarding for every existing command-line argument.
- Corrected menu labels and help text to distinguish previews, confirmed cleanup, and advanced cleanup.

## Safety and Privacy

- Advanced cleanup requires the exact case-sensitive text `CONFIRM` and runs one target at a time.
- Windows Update cleanup only clears the contents of `SoftwareDistribution\Download`, then restores the original `wuauserv` and `BITS` service states even after failures.
- Prefetch cleanup only removes `.pf` files older than 30 days and preserves `ReadyBoot` and `Layout.ini`.
- Component Store cleanup uses supported DISM servicing without `ResetBase`.
- Path guards reject drive roots, profile roots, Windows roots, path escapes, and reparse-point traversal.
- The Web backend listens only on `127.0.0.1`, protects API sessions, and does not terminate unrelated processes when its port is occupied.

## Verification

- PowerShell parser checks passed.
- Seven PowerShell suites passed: CLI cleanup, cleanup safety, backend smoke, branding assets, EXE launcher, release packaging, and package-manager policy.
- `pnpm lint` and `pnpm build` passed for the Web UI.
- `pnpm audit --audit-level high` reported no known vulnerabilities.

## Run

Extract the release ZIP and double-click `NetBoost Command Center.exe`. The EXE displays the Mochi Cat icon and requests Administrator permission through Windows UAC. `NetBoost_Command_Center.bat` remains available as a fallback. Node.js and pnpm are only required for Web UI development, not for using the bundled application.

## Packaging Correction

The portable ZIP was rebuilt to include the branded EXE launcher after the initial v1.0.1 package exposed only the generic Windows batch-file icon. The accompanying `.sha256` asset identifies the corrected ZIP.
