# NetBoost Command Center v1.1.0

This release moves NetBoost to a terminal-only application and adds optional Mole CLI and Win11Debloat managers. DNS, scheduled Auto DNS, the terminal dashboard, cleanup safeguards and the branded Windows launcher remain available.

## Changes

- Removed the React/Vite frontend, HTTP backend, local API, browser assets and JavaScript development dependencies.
- Removed menu option 17 and the legacy Web/port arguments. Unsupported arguments now return exit code 2 with a clear message and help output.
- Moved the 15 cleanup target definitions, confirmation checks, synchronous dispatch and console events into NetBoost.Cleanup.ps1.
- Added Mole CLI at option 18: installation detection, confirmed install/update/uninstall, interactive launch, cleanup preview and disk analysis. Existing Git/Scoop/WinGet channels keep their management method.
- Added Win11Debloat at option 19: verified portable downloads, terminal launch with -CLI, -WhatIf preview, release checks, confirmed updates and managed package removal.
- Added --mole, --win11debloat and --detailed-cleanup-logs terminal flags. Complete cleanup paths remain opt-in.
- Updated EXE/shortcut metadata, documentation and portable packaging to v1.1.0.

## Cleanup and optional-tool behavior

Safe cleanup retains its age and path policies. Recycle Bin and crash dumps require confirmation; advanced actions require the exact case-sensitive text CONFIRM. Windows Update cleanup restores the original wuauserv/BITS states after success or failure. DISM ResetBase is not used.

Mole and Win11Debloat are separate upstream tools, downloaded only after the user confirms. NetBoost validates official release URLs, SHA-256 and package versions. Entering a manager does not install or run cleanup/debloat automatically. When GitHub is unavailable, an existing local copy can still be opened.

Removing Win11Debloat's downloaded scripts does not undo Windows changes already applied with that tool. Registry backups, logs, saved settings, external copies and unrecorded user files are preserved. The integration guides explain ownership and update-channel limits.

## Upgrade and run

1. Download NetBoost-Command-Center-v1.1.0.zip and its .sha256 sidecar.
2. Verify the archive checksum and extract the complete ZIP into a new folder.
3. Run NetBoost Command Center.exe and accept the Windows UAC prompt. NetBoost_Command_Center.bat remains a fallback.

Windows 10/11 and built-in Windows PowerShell 5.1/.NET Framework are sufficient. No Node.js or package-manager installation is required for NetBoost. The EXE is not digitally code-signed.

## Validation

The release validation consists of eight Windows PowerShell suites: terminal-only behavior, CLI Cleanup Center, cleanup safety, Mole integration, Win11Debloat integration, EXE launcher, branding assets and release packaging. Fixtures cover confirmation/cancellation, offline behavior, hash/version failures, path boundaries, service restoration, command-line quoting and terminal-only package contents without applying actual system maintenance.

The portable package contains the EXE/BAT launchers, four runtime PowerShell modules, brand assets, shortcut helper and usage documents. A SHA-256 sidecar accompanies the ZIP.
