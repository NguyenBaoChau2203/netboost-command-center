# NetBoost Command Center v1.2.0

Prepare CS2 once, keep the Windows/NVIDIA configuration across future games, and recover the original settings from durable backups. This release also adds guarded network-throttle diagnostics and optional persistent CS2/voice-only Discord launch priority.

## CS2 preparation — menu 21

- Preview the discovered Steam CS2 path, hardware, AC power and exact settings before applying.
- Enable Game Mode, disable historical background capture, and select the high-performance GPU for CS2 while preserving other GPU preference tokens.
- Use the installed NVIDIA driver API to set only CS2 Prefer Maximum Performance and Highest Available Refresh Rate. Refuse global or shared non-CS2 profiles. Restore original overrides or inheritance rather than resetting the driver database.
- Audit community NIP files read-only. No whole profile import or third-party executable download is needed.
- Keep the original baseline on repeated apply; start a new historical backup only after restoring the prior cycle. Validate machine/account/target identity, record pending changes before writes, verify results and attempt rollback after errors.

## Optional persistent launch priority — menu 21, option 4

Apply once, fully exit and reopen CS2/Discord, and launch them normally in later sessions. The rules supply CS2 AboveNormal and voice-only Discord BelowNormal. No NetBoost background process, service, scheduled task, watcher, custom game launcher or game-process modification is required. FACEIT client, Anti-Cheat processes/services/drivers and security settings remain unchanged.

These optional machine-wide IFEO PerfOptions rules match executable names for every Windows user, including when the other app is closed. PerfOptions is not a supported public Win32 contract, and this release is not certified by FACEIT. A game, launcher or Anti-Cheat may set another priority after launch; NetBoost does not enforce or override it. Check the observed priority in preview/Task Manager and test voice quality. Performance depends on the actual workload; no fixed FPS gain is promised.

Independent backups are under `%ProgramData%\NetBoost\cs2-priority`. Option **7** restores only launch priority, preserving the Windows/NVIDIA preset. Option **3** restores both journals. Restart CS2/Discord after enabling or restoring launch rules. Existing preview-build preparation and per-session priority backups remain restorable.

FACEIT's [FPS/input-lag guidance](https://support.faceit.com/hc/en-us/articles/360015781379-FPS-drops-input-lag-issues) explains possible third-party overlay costs with AC. The CS2 guide includes a comparison with Discord and AC on a non-FACEIT server before queueing. NetBoost leaves the Anti-Cheat configuration alone.

## Network diagnosis — menu 20

Report network tuning state and offer backed-up changes with independent error handling. Preserve existing QoS reservation policy. Reject malformed/unknown original states and refuse restoration without a valid original backup. Use atomic backup writes and completion records; dry-run operations do not mutate settings or backup files.

## Upgrade and run

1. Download `NetBoost-Command-Center-v1.2.0.zip` and its `.sha256` sidecar. Verify the checksum.
2. Extract the complete ZIP into a new folder. Keep existing backups; do not copy personal backup files into a shared package.
3. Run `NetBoost Command Center.exe` and accept UAC. The BAT launcher is also included.
4. Open **21 → 1** to inspect. Apply preparation with **2 → APPLY**. Optionally enable launch priority with **4 → APPLY**, then restart the apps yourself. Close NetBoost and play normally.

Windows 10/11 with built-in Windows PowerShell 5.1 and .NET Framework is sufficient. The EXE is unsigned. No Node.js or extra manager is required for these features. Existing terminal cleanup, DNS, Mole and Win11Debloat workflows remain available.

## Validation and limits

Fifteen Windows PowerShell 5.1 suites cover CLI/menu confirmation, durable journals/locking, rollback and conflicts, old backup compatibility, process identity, NVIDIA scope/layout, registry type round trips, network behavior and packaged EXE/modules/docs/checksum. Priority tests use real durable files with injected registry mutation boundaries; readonly native registry and NVIDIA access are also checked. Disposable HKCU fixture keys are removed after tests.

Development does not apply live CS2/Discord IFEO rules, alter Anti-Cheat, or run a FACEIT match. The owner reported improvement from the earlier preset; the new persistent-priority behavior and performance with FACEIT still require measurement on the actual machine. See [CS2 usage and recovery](../cs2-preparation.md) and [research](../cs2-research.md).
