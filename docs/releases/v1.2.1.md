# NetBoost Command Center v1.2.1

Press **Space** while cleanup prints individual files to hide the remaining details and reach the results without the extra console output.

## Behavior

- Applies to built-in cleanup through menu 9 and shortcuts 10–13. A localized hint appears when interactive file output starts.
- Space hides individual deleted-file, deleted-directory, locked-file and item-error rows for the whole current selection. Cleanup continues synchronously across all selected targets.
- File/folder deletion and failure totals, target-level warnings/errors and completion summaries remain visible. Ongoing disk operations finish before their final counts are shown.
- The next cleanup run shows file details again. The existing detailed-path privacy preference is unchanged.
- Input is checked without blocking or a background thread. Unsupported/redirected console input falls back to ordinary output. No new persistent settings, service, task or watcher.

The cleanup target allowlist, retention ages, confirmation rules, path/reparse-point guards and Windows Update service restoration are unchanged. External Mole/Win11Debloat tools retain their own interfaces. CS2 preparation, persistent launch priority and existing backups remain available as in v1.2.0.

## Upgrade

Download `NetBoost-Command-Center-v1.2.1.zip` and its `.sha256` sidecar, verify the checksum, extract the complete ZIP into a new folder and run the EXE/BAT launcher. Existing CS2/priority backups are outside the application folder and remain intact.

## Validation

The new behavior suite uses real disposable files, including an exclusively locked file, plus injected key input/output to verify deletion/counts, Space-only suppression across targets, summaries/errors, next-run reset and state restoration after exceptions. A Windows PowerShell 5.1 interactive-console probe received an actual Space key and completed the remaining events with a visible summary; it changed no files. Regression suites cover the existing cleanup and other features, packaged EXE/runtime modules and SHA-256 sidecar.
